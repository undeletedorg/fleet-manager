# Shared agent content

This collection is intentionally empty. Existing host skills are audited but have not been imported or assigned.

- `skills/`: explicitly imported skill folders, including references/scripts/assets.
- `instructions/`: shared or agent-specific Markdown sources you choose to write/import.
- [manifest.json](manifest.json): registered skills, assignments, instruction sources, and agent destinations.

Start with `./fleet skills check` or `./fleet instructions check` from the workspace. See [the management guide](../docs/agent-content.md) for importing, assigning, previewing, syncing, and resolving conflicts.
